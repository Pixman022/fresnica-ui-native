# 主按钮配色评审：双主题方案已采用

**最新决定（2026-11-26）**：浅色主按钮采用 `#0F7954` + 白字；深色主按钮采用 `#00CA8A` + `#101312` 深色文字。两种主题的按下态分别使用 `#0C6748` 与 `#00A875`。

以上四组按钮文字对比度均达到 WCAG AA 普通文字 4.5:1 要求；[Native 对比度审计](native-contrast-audit.md)保留计算结果和审核范围。危险操作按钮继续使用独立白色 `onDanger` 文字，避免深色主题下借用 `onPrimary` 导致对比不足。

## 历史决定（2026-10-09，已由本次决定取代）

当时暂时维持 Light `#00A875` / 白字（3.06:1）和 Dark `#00CA8A` / 白字（2.14:1），并记录若干更深绿色的候选方案。该选择并不构成 WCAG 对比度豁免，现已不再是主按钮的现行设计要求。

未解决的弱化文字、部分状态色及控件边界问题，仍须另行审核；这次没有改变独立的成功、失败、收益、损失、警告与风险配色。
