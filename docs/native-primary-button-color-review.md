# 主按钮配色评审：优先保留浅色文字

**状态：待设计确认，未修改生产 Token 或组件视觉。** 范围为 `@fresnica/ui-native` 的普通字号主按钮，
不对 Web 1.0.0 品牌绿色进行隐式修改。

## 来源与计算方式

- 当前 Light 主按钮：`#00A875` 背景、`#FFFFFF` 白字，对比度 **3.06:1**。
- 当前 Dark 主按钮：`#00CA8A` 背景、`#FFFFFF` 白字，对比度 **2.14:1**。
- 测量依据：[Native 对比度审计](native-contrast-audit.md)的 WCAG 相对亮度算法，
  普通字号文字目标为 **4.5:1**。颜色值以共享平台 Token 输出为准。
- 对比图是视觉模拟稿，**图中如有标注与本文件的实测色值/比率不一致，以本文件计算为准**。

## 待选择的方案

### A · 白字 + 稍深的绿色（推荐预览）

- 普通态按钮背景：`#008548`
- 普通态文字：`#FFFFFF`，**4.72:1**
- 按下态按钮背景：`#007A43`
- 按下态文字：`#FFFFFF`，**5.43:1**
- 方案特点：保留清晰的白字与绿色主按钮，但接近 4.5:1 的余量较小；
  必须单独复核按钮半透明/禁用态和混合背景。

### B · 更深绿 + 略柔和的浅色文字

- 普通态按钮背景：`#007A43`
- 普通态文字：`#F4F7F5`，**5.04:1**
- 候选按下态背景：`#006F3B`
- 按下态文字：`#F4F7F5`，**5.83:1**
- 方案特点：浅色文字不使用纯白，明暗更柔和，底色更深、按钮视觉权重更稳。

### 当前方案（仅作对照）

- Light `#00A875` + 白字，3.06:1；Dark `#00CA8A` + 白字，2.14:1。
- 不满足普通字号白字的 4.5:1 对比度要求，不能作为无障碍批准状态。

### 一个需要避免的组合

`#008548` + 柔和白 `#F4F7F5` 的对比度只有 **4.38:1**；
虽然看起来接近方案 A，但仍低于 4.5:1 的目标。浅色文字变暗需要同步加深按钮底色。

## 实施前的设计决策

1. 选择 A 或 B，或提出新的实测通过的颜色组合。
2. 评估浅色、深色模式与 Web 设计规范的一致性。优先**新增/批准专用的主按钮语义颜色角色**，
   而不是未经评估地把所有 `primary`、`positive`、进度条和高亮都加深。
3. 额外检查按钮 pressed、disabled、loading、危险操作状态与主按钮并列使用时的视觉层级。
4. 在 Web 平台 Token 源和 Native 生成文件上建立可追溯的设计审核记录，
   完成 Preview 的 Light/Dark 截图验证后再调整组件与 CI 断言。

**本文件不是变更授权。** 在明确选定 A/B 并确认 Web/Native 兼容性之前，
维持现有颜色不变。相关工作：DS-05、DS-09、DS-11。
